# School ERP Mobile App (Expo / React Native)

## Placeholder for Future Mobile App
This directory is reserved for the future cross-platform mobile application built with React Native & Expo.

### Architecture Integration
- Connects to the School ERP web REST API at `/api/v1/*`.
- Authenticates using Laravel Sanctum Bearer tokens.
- Controlled via the admin setting `app_integration_enabled` (toggleable from System Settings).
- Detailed endpoint contracts, payload schemas, and response examples are documented in `docs/API.md`.
